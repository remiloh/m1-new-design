# M1 Detailing — новый дизайн

Статичный сайт детейлинг-студии M1 Detailing (Глазынино) в новом дизайне: главная, 9 страниц услуг,
цены, работы, отзывы, контакты, о студии и документы.

- `index.html` и папки страниц — HTML
- `css/style.css` — оформление (шрифт Montserrat, лицензия SIL OFL, в папке `fonts/`)
- `js/main.js` — анимации, меню, окна и формы

Посмотреть на компьютере: `python3 -m http.server 8000` в этой папке и открыть http://localhost:8000/

Формы заявок в этой версии никуда не отправляют: приёмник заявок подключается отдельно и в репозиторий не входит.
